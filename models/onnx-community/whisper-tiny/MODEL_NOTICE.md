# Whisper Tiny (ONNX q8)

Este diretório contém a variante ONNX quantizada do modelo multilíngue `openai/whisper-tiny`, disponibilizada por `onnx-community/whisper-tiny` para uso com Transformers.js.

- Modelo base: https://huggingface.co/openai/whisper-tiny
- Conversão ONNX: https://huggingface.co/onnx-community/whisper-tiny
- Revisão empacotada: `ff4177021cc41f7db950912b73ea4fdf7d01d8e7`
- Licença do modelo base: Apache-2.0

Os pesos são incluídos no pacote para que a extensão funcione localmente, sem login, chave de API ou download em tempo de execução.
