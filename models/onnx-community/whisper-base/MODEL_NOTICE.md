# Whisper Base (ONNX q8)

Este diretório contém a variante ONNX quantizada do modelo multilíngue `openai/whisper-base`, disponibilizada por `onnx-community/whisper-base` para uso com Transformers.js.

- Modelo base: https://huggingface.co/openai/whisper-base
- Conversão ONNX: https://huggingface.co/onnx-community/whisper-base
- Revisão empacotada: `0dc963c325ab2554e6dcedbb458decbffb4dc5b1`
- Licença do modelo base: Apache-2.0

Os pesos são incluídos no pacote para que a extensão funcione localmente, sem login, chave de API ou download em tempo de execução.
