# Whisper Small (ONNX q8)

Este diretório contém a variante ONNX quantizada do modelo multilíngue `openai/whisper-small`, disponibilizada por `onnx-community/whisper-small` para uso com Transformers.js.

- Modelo base: https://huggingface.co/openai/whisper-small
- Conversão ONNX: https://huggingface.co/onnx-community/whisper-small
- Revisão empacotada: `36050c46d777d46dc4b5f43f6d90574fc38f8732`
- Licença do modelo base: Apache-2.0

Os pesos são incluídos no pacote para que a extensão funcione localmente, sem login, chave de API ou download em tempo de execução.
